# Flow brand files

The mark is three slices: one done, the current one in the accent, the next one faded. The wordmark is Bricolage Grotesque Bold, converted to outlines, so the SVGs need no font.

| File | Use |
|---|---|
| `flow-logo-on-dark.svg`, `.png` | Mark and wordmark on a dark background |
| `flow-logo-on-light.svg`, `.png` | Mark and wordmark on a light background |
| `flow-mark-on-dark.svg`, `.png` | The mark alone, on a dark background |
| `flow-mark-on-light.svg`, `.png` | The mark alone, on a light background |
| `favicon.svg` | Browser icon, the mark on a dark rounded square |
| `apple-touch-icon.png` | Home-screen icon, 180 × 180 |

Colours: ink `#EAF2F8` on dark and `#0F1720` on light; accent `#7CCBF2` on dark and `#1A7FBF` on light; dark background `#0B0F14`.

Prefer the SVGs; the PNGs have a transparent background, at 1024 px wide for the logo and 512 px for the mark. Keep clear space around the logo of at least the height of one slice, and don't recolour the slices one by one.
